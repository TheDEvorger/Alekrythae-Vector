# Changelog

All notable public changes to Ałek’ryŧhæ Vector will be documented here.

## [0.1.0] - Initial public release

- Added local raster-to-SVG conversion powered by VisionCortex VTracer.
- Added color photo tracing with stacked hierarchy.
- Added true 2–1024 color control.
- Added high-fidelity 1024 mode without a hidden color cap.
- Added detail, curve, cleanup and quality controls.
- Added black-and-white tracing.
- Added optional background removal.
- Added local Node.js engine installation and health checks.
- Added SVG validation to reject embedded raster image nodes.
